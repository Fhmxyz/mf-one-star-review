# One-Star Review of Sleep

A deadpan one-star review of sleep, filed in earnest: it never shows up when you are in bed waiting for it, arrives uninvited in meetings, and charges eight hours a night for the privilege. The program writes this single line (149 characters) to `/output/entry.txt`, where the competition's gate checks it and the house judge compares it against the other reviews.

## Run it

`python3 main.py`
